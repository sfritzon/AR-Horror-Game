# 🎮 Small Theft Auto: Lag-On

*A micro–chaotic, slightly–illegal, proudly–laggy GTA parody.*

Welcome to **Small Theft Auto: Lag-On**, the only GTA-inspired game where the police population outnumbers the civilians and they're all suspiciously eager to punch the soul out of you. Explore the town, shoot, run, steal cars, throw grenades in slow motion, and try not to get turned into confetti by angry cops.

This game is a student project featuring movement, combat, driving, grenade slow-motion, quests, saving/loading, and a working in-game shop.

---

## 🌆 Gameplay Overview

Small Theft Auto is a third-person mini–sandbox where you:

*   Run around a small city
*   Fight endless waves of police NPCs (the only citizens who still pay taxes)
*   Throw grenades in glorious slow motion
*   Steal cars and run over said police NPCs
*   Pick up and complete quests
*   Buy ammo and grenades at the in-world shop
*   Save and load your progress anytime

**Danger, explosions and questionable life decisions included.**

## 🕹️ Controls

### **Movement**

| Action          | Key           |
| :-------------- | :------------ |
| Move            | `W` `A` `S` `D` |
| Sprint          | `Shift`       |
| Jump            | `Space`       |
| Rotate Camera   | Mouse         |

### **Weapons**

| Action              | Control       |
| :------------------ | :------------ |
| Open weapon menu    | `Tab`         |
| Change weapon       | Mouse Wheel   |
| Shoot               | `Left Click`  |
| Aim                 | `Right Click` |
| Reload              | `R`           |

### **Grenades**

| Action                          | Control                     |
| :------------------------------ | :-------------------------- |
| Enter / Exit grenade mode       | `Middle Mouse Click`        |
| Throw grenade                   | `Left Click`                |
| Cancel grenade mode             | `Right Click`               |
| Aim arc (slow motion active)    | Move camera                 |

> **Note:** In grenade mode, the game enters slow-motion, and an arc visual helps you aim.

### **Interaction**

| Action                         | Key   |
| :----------------------------- | :---- |
| Enter / exit vehicle           | `E`   |
| Interact with NPC quest or shop| `E`   |

### **System**

| Action        | Key   |
| :------------ | :---- |

## 🔫 Combat

*   Six differents weapons.
*   NPC cops chase you and deal damage on contact.
*   Weapons have their own magazine and reserve ammo.
*   HUD shows ammo, grenades, health, stamina and money.

---

## 💣 Grenade Slow-Motion Mode

The game features a stylish **“cinematic mode”**:
1.  Press `Middle Mouse Click` to enter slow-motion grenade mode.
2.  Time slows to **20% speed**.
3.  Player movement slows for dramatic effect.
4.  A trajectory arc appears.
5.  Throw the grenade with `Left Click`.

*You are basically Neo, but more explosive.*

---

## 🚓 Police NPCs

The world is populated exclusively by **aggressively dedicated police officers**.  
They:
*   Chase the player when nearby
*   Deal damage on contact
*   Can be shot or blown up
*   Drop money when defeated

*They never stop coming — their loyalty is admirable, if not slightly terrifying.*

---

## 🛒 Shop System

There is an in-game shop where you can:
*   Buy grenades
*   Buy ammunition

Interact with the shop.

---

## 📜 Quest System

Throughout the city, you'll find **blue hologram-looking quest figure**.  
Walking into one automatically:
*   Gives you a quest
*   Displays the objective
*   Rewards you with money when completed

*It's like an RPG, but everyone trying to kill you is a cop.*

---

## 🚗 Vehicles

*   Cars can be entered/exited with `E`.
*   Player control switches seamlessly.
*   Vehicles have health.
*   You can run over NPCs (they are not fans of this).

---

## ❤️ HUD Elements

The UI displays:
*   Health bar
*   Stamina bar
*   Ammo (mag + reserve)
*   Grenade count
*   Money
*   Vehicle health bar (when inside a car)
*   Fuel bar (when inside a car)
*   Interaction prompts

---

## 💾 Saving & Loading

*   Press `K` anytime to save your game.
*   The **"Continue"** button on the menu loads the latest save.
*   Saves include player position, health, money, ammo, grenades, and more.
